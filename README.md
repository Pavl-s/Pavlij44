# Frenzy Harvest

## Суть гри
Гравець бере на себе роль відважного мандрівника, який досліджує небезпечні землі, населені ворожими створіннями. На своєму шляху герой зустрічає підступних грибів-монстрів та агресивних гоблінів, яких необхідно перемагати.

Мета гри полягає в тому, щоб подолати всіх ворогів, уникати небезпек та пройти до виходу. Для перемоги гравець повинен демонструвати швидку реакцію, вчасно атакувати супротивників і не дозволити їм завдати занадто багато шкоди герою.

## Вид гри
